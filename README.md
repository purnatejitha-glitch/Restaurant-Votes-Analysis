# 📊 Restaurant Votes Analysis

## Project Overview
This project analyzes restaurant voting data to identify restaurants with the highest and lowest numbers of votes and investigate the relationship between the number of votes and restaurant ratings.

## 🎯 Objectives
- Identify the restaurant with the highest number of votes.
- Identify the restaurant with the lowest number of votes.
- Analyze the correlation between votes and aggregate ratings.
- Visualize voting patterns and restaurant popularity.

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📂 Dataset
The analysis uses the Cognifyz restaurant dataset, which contains restaurant names, votes, aggregate ratings, and other restaurant-related information.

## 🔍 Analysis Performed
1. **Highest Votes:** Identify the restaurant receiving the most votes.
2. **Lowest Votes:** Identify the restaurant receiving the fewest votes.
3. **Correlation Analysis:** Calculate the correlation coefficient between votes and restaurant ratings.
4. **Data Visualization:** Use scatter plots and other charts to examine voting patterns.

## 📈 Key Insights
- Determine which restaurants receive the most and fewest customer votes.
- Examine whether restaurants with more votes tend to have higher ratings.
- Understand the relationship between restaurant popularity and customer ratings.
